# Claims → evidence map

Each row ties one quantitative claim to the committed file that records it, and gives a command that prints the value from the repository root. Every path below exists in this tree. All commands are read-only and need only Python 3 (no model downloads). The audit re-runs in C1–C3 also need the packages in `requirements-shared.txt`.

**Scope:** this table covers the headline claims listed below. It was **not** checked line by line against the final paper source, so the *paper section* column is left blank (`—`). A claim that appears in the paper but not in this table has not been mapped yet; it has not been shown to be unsupported.

Conventions:
- **drop (pp)** means accuracy without the trigger minus accuracy with it, in percentage points. A positive drop means the trigger lowers accuracy.
- **Text audit** is the text-only distributional audit (`scripts/run_distributional_audit_textonly.py`). Its `joint_auc` field is the AUC of a classifier separating trigger-absent from trigger-present responses; 0.5 is chance.

## Claims with no file in this repository

Every claim listed above has a file. Claims that rest on artifacts too large for git (LoRA adapter weights under `adapters/`) are covered by their recorded outputs. The adapter SHA-256 values are in each experiment's `adapter_sha256.txt` or `*_summary.json`, and the weights themselves are not included.

## Experiment index

Each `results/resubmission/E*/SUMMARY.md` and `results/e15_active_check/SUMMARY.md` states its protocol, run window, decision rule and tables. The preregistered plans for E9–E15 are in `docs/plan/PLAN_E*_2026-09-30.md`, and E1–E5 recipes are in `docs/runbooks/`.
